# CCCD Reader Frontend (Flet)

Ứng dụng giao diện đa nền tảng (Desktop/Mobile) viết bằng Flet để chụp ảnh, tải lên và hiển thị thông tin giấy tờ tùy thân CCCD / GPLX.

## Hướng dẫn chạy

```bash
# Cài đặt thư viện phụ thuộc
pip install flet flet-camera flet-permission-handler httpx

# Chạy ứng dụng trên máy tính
flet run main.py
```
